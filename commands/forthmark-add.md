allowed-tools: Bash({CLI}:*)
---

!`{CLI} add . 2>&1`

上面是接入结果和记录规则。接入成功后：

1. 从现在起按上面的规则维护状态文件（路径见输出），不要在项目目录里创建或修改任何状态相关文件。
2. 如果状态文件里还只有初始内容，现在初始化它：快速浏览本项目的 README、docs、todo / bug / 计划类 md 和最近 20 条 git log，提炼出目标、阶段、任务、等待项、bug、决策、下一步。只写人需要一眼看到的东西，宁少勿多；看不出来的不要编，留空即可。从 git log 或文档补记的历史事件，只知道日期时用当天 `T00:00` 加时区，不要估具体钟点。
3. 运行 `{CLI} docs` 查看项目里的文档，为主要文档（方案、需求、指南、进度、待办、AGENTS.md 等）各运行一次 `forthmark.py doc` 登记角色和一句话作用；README 和不重要的文件可以跳过。
4. 运行校验命令，然后运行 `{CLI} show .` 并把输出原样放进代码块展示。
5. 最后告诉用户：面板在 `~/.forthmark/panel.html`，以后每轮结束会自动更新。
